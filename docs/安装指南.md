# 安装指南

## 1. 前提

- Windows 电脑与 Android 手机都已安装并登录 Tailscale。
- Windows 已安装 OpenSSH Server，`sshd` 正在运行。
- 防火墙只允许预期的 Tailnet 手机访问 TCP 22。
- Windows 用户拥有账户密码；App 不能使用 Windows Hello PIN 登录 SSH。
- DSH CLI 可在该 Windows 用户环境中运行。

## 2. 安装 DSH 插件

在包含发布文件的目录运行：

```powershell
dsh plugin --profile web add .\dsh-tailnet-mobile-plugin-1.0.1.tgz
```

然后重启 `dsh web`。插件使用标准 `cordis.patch.yml` 挂载，不修改 DSH 核心源码。

## 3. 配置 Tailscale Serve

电脑上配置 Serve，把 DSH 的 3080 端口暴露到 Tailnet：

```powershell
& "C:\Program Files\Tailscale\tailscale.exe" serve --bg 3080
```

确认状态：

```powershell
& "C:\Program Files\Tailscale\tailscale.exe" serve status
```

移动端网址为：

```text
https://电脑MagicDNS名称/m
```

原始 Web 为同一个地址的根路径 `/`。

> 插件会信任 Tailscale Serve 注入的 Tailnet 用户身份头，因此 Tailnet 内手机直接打开 `/m` 即可访问移动端界面，无需二维码配对。
> 如果你希望使用更严格的 app capability 门禁，可另外配置 `tailnetCapability` 并用 `--accept-app-caps` 启动 Serve；这不是必须步骤。

## 4. 准备计划任务

APK 默认控制名为 `DSH Web` 的 Windows 计划任务。任务动作应在当前 Windows 用户环境中执行：

```text
dsh web --port 3080 --trusted-host 电脑MagicDNS名称
```

可先使用 `scripts/setup-windows-host.ps1` 创建或更新该任务。脚本不会自动安装 OpenSSH，也不会修改 Tailnet 云端策略。

## 5. 安装 APK

安装 `dsh-mobile-v1.3.0.apk`。首次打开填写：

- SSH 主机：Tailnet IP 或 MagicDNS 名称。
- SSH 端口：通常 22。
- Windows 用户名。
- Tailscale Serve 根地址：`https://电脑MagicDNS名称`。
- Windows 账户密码。

首次 SSH 连接时，在电脑运行以下命令核对指纹：

```powershell
ssh-keygen -lf C:\ProgramData\ssh\ssh_host_ecdsa_key.pub -E sha256
```

## 6. 更新与卸载

安装新版 tarball 后重启 `dsh web`。Android APK 更新必须使用与旧版相同的签名证书；否则 Android 会要求卸载旧版，卸载会清除 App 的已保存连接信息和 SSH 主机公钥记录。
